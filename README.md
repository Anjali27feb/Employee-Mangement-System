# Employee Management System (EMS)

A full-stack Employee Management System built using **Java Spring Boot** and **MySQL**. This project is designed to manage employee information efficiently through RESTful APIs.

The application follows a **layered architecture**:

- **Controller Layer** – Handles HTTP requests and responses.
- **Service Layer** – Contains the business logic of the application.
- **Repository Layer** – Communicates with the MySQL database using Spring Data JPA.
- **DTOs and ModelMapper** – Used for clean data transfer between different layers.

### Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

### Features Implemented
- Add employee details
- View employee information
- Update employee details
- Delete employee records
- RESTful API development
- Database integration using Spring Data JPA
- API testing using Postman

This project demonstrates my understanding of **Java backend development, Spring Boot, REST APIs, database integration, and layered application architecture**.
